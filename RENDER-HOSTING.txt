HelpCentre Pro — easy Render hosting (ebubeprimex)
==================================================

GOAL
----
- Code lives on GitHub account: ebubeprimex
- Every git push to GitHub auto-deploys on Render
- Frontend + Backend + Postgres created from one Blueprint


STEP 1 — Create the GitHub repo (once)
--------------------------------------
1. Sign in as: ebubeprimex
2. Create a new repository named: Help_Center_Pro_webapp
   (private is fine)
3. Leave it EMPTY (no README / .gitignore / license)


STEP 2 — Push this project to ebubeprimex (once)
------------------------------------------------
Open PowerShell in this folder and run:

  git remote add ebubeprimex https://github.com/ebubeprimex/Help_Center_Pro_webapp.git
  git push -u ebubeprimex master

If GitHub asks you to sign in, use the ebubeprimex account.

Optional — push to BOTH accounts with one command forever:

  git remote set-url --add --push origin https://github.com/Okechukwu2002/Help_Center_Pro_webapp.git
  git remote set-url --add --push origin https://github.com/ebubeprimex/Help_Center_Pro_webapp.git
  git push origin master


STEP 3 — Deploy on Render (once, ~5 minutes)
--------------------------------------------
1. Go to: https://dashboard.render.com
2. Sign in with GitHub → authorize ebubeprimex
3. Click: New +  →  Blueprint
4. Select repo: ebubeprimex/Help_Center_Pro_webapp
5. Render reads render.yaml and creates:
     - helpcentre-pro-db   (Postgres)
     - helpcentre-pro-api  (Backend)
     - helpcentre-pro-web  (Frontend)
6. Before Apply, set these Blueprint env values (copy-paste):

   On helpcentre-pro-api:
     FRONTEND_URL = https://helpcentre-pro-web.onrender.com
     CORS_ORIGINS = https://helpcentre-pro-web.onrender.com
     RESEND_API_KEY = (same re_... value as local backend .env)
     RESEND_WEBHOOK_SECRET = (same whsec_... value as local backend .env)
     EMAIL_FROM = HelpCentre Pro <noreply@helpcentrepro.com>
     SUPPORT_EMAIL_FROM = HelpCentre Pro Support <support@helpcentrepro.com>

   On helpcentre-pro-web:
     VITE_API_URL = https://helpcentre-pro-api.onrender.com

   If Render assigns different public URLs after create, update those three
   URL fields in the dashboard and Manual Deploy the web service
   (VITE_API_URL is baked in at build time).

7. Click Apply

EVERYDAY WORKFLOW
-----------------
1. Change code locally
2. git add .
3. git commit -m "your message"
4. git push ebubeprimex master
   (or git push origin master if dual-push is configured)

Render auto-deploys from the GitHub push. No manual upload.


NOTES
-----
- Free Render services sleep after idle time; first request may take ~30–60s.
- Frontend must be rebuilt when VITE_API_URL changes (set it before first build).
- After URLs are final, you can update FRONTEND_URL / CORS_ORIGINS / VITE_API_URL
  in the Render dashboard and trigger a Manual Deploy.
